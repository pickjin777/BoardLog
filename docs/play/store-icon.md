# 스토어 아이콘

작성일: 2026-11-24. 콘솔에 올리지 않았다. 최종 그림인지는 소유자가 본다.

비교용으로 두었던 이전 시안 폴더는 작업 트리에서 뺐다. 그 파일은 git 이력에만 있다.

## 결정

바탕은 네이비 `#0E1628`이다. 아이콘·스플래시·적응형 배경의 모서리는 이 색이고, `check:secrets`가 확인한다. 가운데는 골드 `#E2B657` 테두리의 갈색 상자다. 글자 B는 쓰지 않는다.

적응형 전경은 108 기준 지름 66의 안전 원 안에 상자를 둔다. 마스크용 512도 가운데 80% 원 안에 상자를 둔다. 스토어 아이콘은 512×512, 8비트 RGBA(채널 4, 32비트)다. 피처 그래픽은 1024×500, 알파 없는 PNG다.

피처 그래픽 글자는 "보드로그", "나만의 보드게임 보물 상자"다. 그릴 때 기기의 WenQuanYi Micro Hei가 있으면 그 글꼴로 픽셀만 남긴다. 글꼴 파일은 앱 번들에 넣지 않는다. 화면 글꼴은 시스템 산세리프다.

그림은 `scripts/draw-brand-assets.py`가 만든다. 실행에는 로컬 Pillow가 필요하다. 앱 의존성이 아니다.
