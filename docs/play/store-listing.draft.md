# 스토어 등록정보 초안

작성일: 2026-11-10. 게시·제출용 최종본이 아니다. 플레이 콘솔에 넣지 않았다. 확인하지 못한 수치, 순위, 사용자 수는 적지 않았다.

앱 이름은 매니페스트의 `short_name`과 같다. 짧은 설명과 자세한 설명은 이 브랜치의 화면과 코드에 있는 동작만 말한다.

## 앱 이름

`보드로그`

글자 수: 4. 콘솔 한도는 30자. 영문 `Board Log`는 앱 헤더의 작은 표시에만 있고, 스토어 이름에는 넣지 않는 쪽을 제안한다. 이름 최종안은 소유자가 정한다.

## 짧은 설명

한도 80자. 아래 문장의 글자 수는 Python `len`으로 센 코드포인트 수다.

```
가지고 있는 보드게임과 플레이 기록(사람, 점수, 사진)을 이 기기에 남깁니다.
```

글자 수: 44.

## 자세한 설명

한도 4000자. 콘솔에 붙여 넣을 본문만 아래 코드 블록이다. 블록 안 글자 수는 749다. Python `len`으로 끝의 줄바꿈은 빼고 셌다.

```
보드로그는 가지고 있는 보드게임과 플레이 기록을 이 기기에 모아 두는 앱입니다.

소장
게임 이름, 인원, 플레이 시간, 난이도, 장르, 보관 장소, 상태, 구매 정보를 등록합니다. 앱에 들어 있는 게임 목록에서 골라 넣거나, 목록에 없으면 직접 입력합니다.

플레이
날짜, 시작과 끝, 장소, 함께한 사람의 이름과 점수, 나의 결과, 짧은 감상, 사진을 남깁니다. 게임을 열면 그 게임의 지난 기록을 볼 수 있습니다. 게임과 연결하지 않고 같은 이름으로만 남긴 기록도, 그 이름의 게임이 하나일 때 같이 보여 줍니다.

주고받기
기록 링크를 보내면 받는 사람이 자신의 기기에 그 기록을 넣을 수 있습니다. 링크에는 게임 이름, 날짜, 장소, 함께한 사람의 이름과 점수가 들어갑니다. 사진과 감상은 링크에 넣지 않습니다.
소장 목록 문구를 복사해 메신저에 붙여 넣을 수 있습니다. 목록을 PDF로 저장하거나 인쇄할 수 있습니다.
마이페이지에서 JSON 파일로 백업하고, 그 파일로 복원할 수 있습니다.

저장
게임, 기록, 사진, 직접 만든 계정의 이메일과 비밀번호는 이 기기의 브라우저에 있습니다. 다른 기기에서 보려면 JSON 백업 파일을 직접 옮겨야 합니다. 기기를 바꾸거나 브라우저 데이터를 지우면 기록이 사라질 수 있습니다.

사진으로 이름 읽기
서버에 사진 인식이 켜져 있을 때만, 고른 상자 사진으로 게임 이름을 읽습니다. 꺼져 있으면 준비 중이라고 안내하고 사진은 나가지 않습니다.

결제
앱 코드에는 결제 기능이 없습니다.
```

## 카테고리 제안

제안: 생산성 (Productivity).

이유: 보드로그는 플레이하는 게임이 아니라 소장 목록과 기록 도구다. 게임 카테고리는 설치 후 바로 플레이하는 앱으로 읽힐 수 있다.

대안: 라이프스타일 (Lifestyle). 취미 기록을 앞세울 때.

이 제안은 콘솔에서 고르지 않았다. 카테고리 목록의 현재 이름도 콘솔에서 다시 대조해야 한다. 미확인.

## 스크린샷에 담을 화면 후보

폰 스크린샷은 최소 2장이다. 아래는 이미 있는 화면이다. 테스트 계정, 토스트, 개발자 도구, "준비 중" 안내가 겹친 조사 화면은 스토어 원본으로 쓰지 않는다. 이 저장소에는 스토어용으로 잘라 둔 그림이 없다.

| 순서 | 화면 | 담으면 좋은 점 |
|---|---|---|
| 1 | 홈. 최근 플레이와 많이 한 게임 | 기록을 모아 보는 첫 화면 |
| 2 | 내 게임. 게임 카드가 있는 목록 | 소장 목록 |
| 3 | 게임 상세. 그 게임의 지난 플레이 | 한 게임의 기록 |
| 4 | 플레이 기록 한 건의 상세, 또는 기록을 적는 화면 | 사람, 점수, 결과 |
| 5 | 마이페이지의 JSON 백업 | 기기 안에만 있다는 설명과 맞음 |

피처 그래픽 1024×500은 없다. 소유자가 구도를 정한다.

## 이 문장에 넣지 않은 것

- 다른 기기와 자동으로 동기화된다.
- 사진 인식이 항상 켜져 있다. 또는 이름을 틀리지 않는다.
- 오프라인에서 기록 편집까지 된다. 서비스 워커는 마지막으로 연 앱 껍데기를 다시 보여 주는 시도이고, 기록 저장의 오프라인 보장은 검증하지 않았다.
- 사용자 수, 별점, 가격, "무료". 결제 코드가 없다는 문장만 자세한 설명에 있다.
