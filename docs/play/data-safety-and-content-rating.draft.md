# Data safety 답변 초안과 콘텐츠 등급 설문 예상

작성일: 2026-11-10. 고친 날: 2026-11-12. 플레이 콘솔에 입력하지 않았다. 콘솔의 질문 문장은 이 세션에서 열지 못했다. 아래 질문 이름은 도움말에 나오는 구분을 따라 적은 것이고, 화면의 현재 문구와 다르면 미확인이다. 선언이 앱과 다르면 조치될 수 있으므로 소유자가 콘솔에서 고친다.

2026-11-12에 [data-safety.md](data-safety.md)와 어긋나던 칸을 고쳤다. 지금 패키지에는 광고와 인앱 결제가 없다. 포장은 Capacitor(`com.pickjin.boardlog`)다. 계정 삭제는 앱 안에 있다. 안드로이드 앱은 Vercel 방문 통계를 보내지 않는다.

코드 위치는 이 브랜치 기준이다.

## Data safety에서 "수집"의 뜻

도움말은 기기 밖으로 전송되는 데이터를 수집으로 본다. 브라우저 안에만 있는 데이터는 그 정의에서는 수집이 아니다. 출처는 [Data safety](https://support.google.com/googleplay/android-developer/answer/10787469). 이 문장이 2026-11-10 콘솔 질문과 같은지는 미확인.

## 수집·공유한다고 적을 초안

| 데이터 | 수집 | 공유 | 코드 근거 | 목적 | 선택 여부 |
|---|---|---|---|---|---|
| 사진 | 예, 조건부 | 예. Vercel 함수를 거쳐 Google Gemini | 설정의 사진 인식이 켜져 있고, 사용자가 확인란을 직접 체크해 동의한 뒤에만 `src/services/gameScanner.ts`가 POST `/api/scan-games`로 줄인 이미지(최대 4장, 긴 변 1600, JPEG, EXIF 제거)를 보낸다. 끄거나 동의 전에는 GET도 POST도 하지 않는다. `api/scan-games.ts`가 Gemini `generateContent`에 넣는다. 키 `GEMINI_API_KEY`가 없으면 503이고 사진을 넘기지 않는다. 함수는 이미지를 DB에 쓰지 않는다. 화면에는 제공자 원문과 모델 목록을 보여 주지 않는다 | 앱 기능 (상자 이름 읽기) | 선택. 기본 스위치는 켜짐이지만 동의는 미리 체크되지 않는다. 설정에서 끄거나 동의를 철회하면 그 경로는 닫힌다 |
| 앱 상호작용 (방문) | 이 안드로이드 앱은 아니오. 웹사이트는 예 | 웹만 Vercel Web Analytics. 광고 회사로 넘기는 코드는 없다 | `src/components/VercelAnalytics.tsx`. localhost에서는 렌더하지 않음. 앱 WebView 출처는 `https://localhost`. 주소의 `#` 제거 | 분석 | 앱 패키지에 대해서는 수집 아니오. 웹을 양식에 넣을지는 사용자 확인 필요 |
| 앱 상호작용 (기능 횟수) | 측정 ID가 있을 때만 | Google Analytics | `src/services/analytics.ts`, 허용 목록 `src/utils/analyticsEvents.ts`. 이름·제목·장소·점수·사진·공유 조각은 거절. `allow_google_signals`와 `allow_ad_personalization_signals`는 false | 분석 | 프로덕션 묶음에 ID가 없으면 스크립트를 넣지 않는다. 2026-11-10 공개 묶음에서 `G-` 측정 ID는 찾지 못했다 |

사진의 서버 보관과 Vercel·Google의 보관 기간은 미확인. 처리 중만 쓰고 버리는지(ephemeral)는 우리 코드가 DB에 안 쓴다는 범위에서만 말할 수 있다.

암호화: 사이트와 API는 HTTPS다. 수집된 데이터의 저장 중 암호화가 Vercel·Google 기본값 이상인지는 미확인.

## 수집이 아니라고 적을 초안

기기 안에만 있고, 위 표의 경로로 나가지 않는 항목이다.

| 데이터 | 어디에 있나 | 근거 |
|---|---|---|
| 이메일, 닉네임, 비밀번호 해시 | 이 브라우저. 비밀번호는 PBKDF2-SHA256 210000회 | `src/services/storage.ts`의 `signUp` |
| 게임, 플레이, 함께한 사람 이름, 점수, 장소 글, 감상, 기록 사진 | IndexedDB 또는 localStorage | `src/services/storage.ts`. 클라우드 업로드 코드 없음 |
| 대략적 위치나 GPS | 권한 요청이 없다. 장소는 사용자가 적은 글이다 | 위치 API 호출을 찾지 못함 |

공유 링크(`src/utils/sharedPlay.ts`)는 `#play=` 조각에 게임 이름, 날짜, 장소, 사람 이름, 점수를 넣는다. 브라우저는 이 조각을 우리 서버로 보내지 않는다. 사용자가 링크를 직접 보낸다. Data safety의 "제3자 공유"에 이 경우를 넣어야 하는지는 콘솔 질문 문장에 따라 갈린다. 미확인. 넣지 않는 쪽으로 적되, 콘솔이 "사용자가 다른 사용자에게 보내는 정보"를 물으면 예라고 고친다.

## 보안 질문 초안

| 질문 | 초안 | 근거 |
|---|---|---|
| 전송 중 암호화 | 예. 앱이 여는 주소는 HTTPS | 배포 도메인 `https://board-log.vercel.app`. 로컬 개발 서버는 예외 |
| 사용자가 데이터 삭제를 요청할 수 있나 | 예. 마이 화면에서 그 계정의 게임, 플레이, 로그인 정보를 이 기기에서 지운다. 앱 밖 안내 초안은 `public/account-deletion/`이나 공개 URL은 아직 없다 | `storage.deleteAccount`. 서버 계정은 없다. 문의 메일은 아직 자리표시자 |
| 독립 보안 심사 | 아니오 | 코드나 문서에 심사 기록이 없다 |

## 콘텐츠 등급 설문 예상

IARC 설문이 등급을 정한다. 이 초안은 등급 이름(전체이용가 등)을 단정하지 않는다. 콘솔 질문의 현재 문장은 미확인이다.

앱 종류: 게임 플레이 앱이 아니라 기록 도구. 카테고리 제안은 [등록정보 초안](store-listing.draft.md)에 있다.

| 설문에서 보통 묻는 것 | 예상 답 | 코드 근거 | 확실함 |
|---|---|---|---|
| 폭력, 공포, 성적 내용, 약물 | 앱이 그리는 콘텐츠 없음 | UI 문자열과 시드 데이터는 게임 정보와 기록 칸이다. 폭력·성적 묘사 화면을 찾지 못함 | 앱이 제공하는 문장에 한정. 사용자가 사진이나 감상에 무엇을 넣는지는 제한하지 않음 |
| 욕설 | 앱 문장에는 없음. 필터도 없음 | 메모·감상·이름은 자유 입력. 공개 게시판이나 채팅은 없음 | 설문 문장이 "사용자가 욕설을 입력할 수 있나"이면 예. 문장을 보지 못함. 미확인 |
| 도박, 현금 베팅, 경품 | 없음 | 출시 패키지에 결제·베팅·무작위 상자 코드 없음. 광고도 없음 | 사용자가 기록하는 보드게임에 운 요소가 있을 수 있다. 그건 앱의 기능이 아님 |
| 사용자끼리 앱 안에서 대화하거나 콘텐츠를 올림 | 앱 안 대화, 공개 피드, 다른 계정이 내 기록을 보는 기능 없음 | 계정은 이 브라우저 안에만 있음 | 확실 |
| 사용자가 정보를 다른 사람에게 보낼 수 있나 | 예. 공유 링크와 운영체제 공유 시트 | `src/utils/sharedPlay.ts`, 게임 상세의 공유 버튼. 링크에 사람 이름과 점수가 들어감. 사진은 링크에 없음 | 확실 |
| 실제 위치 공유 | 아니오. GPS 권한 없음. 장소는 글 | 위치 권한 코드를 찾지 못함 | 설문 문장이 자유 입력 장소까지 물으면 미확인 |
| 디지털 구매 | 없음 | 출시 패키지에 결제 라이브러리와 구매 화면이 없다(D-048). 다시 켜면 설문을 다시 냄 | 확실. 자세한 데이터 보안 답은 [data-safety.md](data-safety.md) |
| 제한 없는 웹 탐색 | 아니오. 주소창은 없다 | 페이지 출처는 `https://localhost`. 시드 표지는 앱 안 그림이라 `images.unsplash.com`을 열지 않는다. 사진 인식이 켜져 있고 동의한 뒤 사진을 보낼 때만 `https://board-log.vercel.app/api/scan-games`를 연다. 측정 ID가 없는 이 빌드는 Google Analytics를 열지 않는다. 카카오 앱 키는 비어 있어 `sharer.kakao.com`을 열지 않는다. 광고·결제 주소는 열지 않는다. 사용자가 게임 칸에 직접 적은 이미지 주소가 있으면 WebView가 그 주소의 그림을 연다 | 사용자가 주소창에 아무 사이트나 넣는 기능은 없다 |

사용자가 올린 사진과 글을 앱이 검토하거나 신고받는 절차는 없다. 설문이 "사용자 생성 콘텐츠를 조정하는가"를 물으면, 조정하지 않는다고 답하는 쪽이 코드와 맞다. 질문 문장은 미확인.

## 권한과 광고 식별자

출시 패키지(`boardlog.monetization=false`)의 매니페스트 권한은 `android.permission.INTERNET`뿐이다. 사진 선택은 시스템 사진 고르기를 쓰며 `READ_MEDIA_IMAGES`나 `CAMERA`를 요청하지 않는다. `AD_ID`와 `com.android.vending.BILLING`은 `tools:node="remove"`다. 광고 식별자를 읽지 않고 결제를 시작하지 않는다.

`android:allowBackup="false"`이고 `dataExtractionRules`와 `fullBackupContent`는 클라우드 백업과 기기 간 전송에 데이터를 넣지 않는다. 다른 기기로 옮기는 공식 경로는 마이 화면의 JSON 파일이다. 그 파일에는 게임, 플레이, 수집 진행(`progress`)이 들어간다. 진행 칸이 없는 예전 파일도 읽는다.
